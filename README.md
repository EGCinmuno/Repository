# Portfolio — Lorenzo Erra

Portfolio de herramientas web desarrolladas para la docencia, la investigación y la práctica en genómica clínica e inmunología.

## Proyectos incluidos
- **ClinGenIO**: Asistente con inteligencia artificial para la clasificación e interpretación de variantes según pautas ACMG/ClinGen con citas científicas.
- **Aiuda-predictor (EuGenIA)**: Herramienta pedagógica de análisis molecular de variantes en el mapa exón-intrón y predicción de marco de lectura.
- **Guía Visual ACMG (Torta)**: Diagrama y representación visual interactiva de los criterios de clasificación ClinGen/ACMG.
- **Interactive IEI — IUIS Explorer**: Plataforma para la exploración interactiva de genes y fenotipos según la clasificación IUIS de Errores Innatos de la Inmunidad.
- **EGCinmuno — Laboratorio Virtual**: Entorno práctico de examen y casos clínicos para la Especialización en Genética Clínica e Inmunología.
