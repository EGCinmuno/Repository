Genómica Clínica · Bioinformática · Desarrollo Web

Lorenzo Erra

Bioinformático · Genómico Clínico · Escuela de Genómica Clínica (EGC)

Desarrollo herramientas web orientadas a la enseñanza y la práctica en genómica clínica e inmunología. Cada proyecto nació de una necesidad docente concreta y está pensado para ser accesible desde el navegador, sin instalación.

Proyectos

  • ClinGenIO

    Asistente de IA especializado en la clasificación de variantes genéticas según las guías ACMG/AMP y ClinGen. Responde consultas con evidencia de 18 publicaciones científicas indexadas.

    Genómica · IA LLM

  • Aiuda-predictor

    Plataforma pedagógica para el análisis molecular de variantes. Visualiza la variante en el mapa exón-intrón, a nivel de bases y predice el nuevo marco de lectura.

    Genómica · Visualización HTML JavaScript Canvas

  • Guía Visual ACMG — Torta

    Representación visual interactiva de los criterios de clasificación ClinGen/ACMG. Facilita la comprensión del peso relativo de cada criterio en el proceso de clasificación.

    Genómica · Visualización HTML JavaScript Sin deploy aún

  • Interactive IEI — IUIS Explorer

    Plataforma interactiva para la exploración de genes y fenotipos según la clasificación IUIS de Errores Innatos de la Inmunidad. Acceso restringido para docencia y consulta especializada.

    Inmunología HTML JavaScript Supabase

  • EGCinmuno — Laboratorio Virtual

    Plataforma de examen práctico para la Especialización en Genética Clínica e Inmunología. Laboratorio virtual con casos clínicos, panel docente y seguimiento de alumnos.

    Inmunología · Examen

  • Personal GitHub

    Bioinformatician, PhD in the intersection of clinical genomics, data science, and artificial intelligence. I enjoy transforming complex biological and clinical data into intuitive analyses, visualizations and decision-support tools.

    Github Proyects

Sobre mí

Bioinformático y Genómico Clínico con formación en la Escuela de Genómica Clínica (EGC), un espacio de formación avanzada en genómica, bioinformática y medicina de precisión de la Facultad de Ciencias Exactas y Naturales, UBA.

Me especializo en el desarrollo de herramientas web educativas que hacen accesibles conceptos complejos de genómica clínica e inmunología, tanto para el aula como para la práctica clínica y la investigación.
